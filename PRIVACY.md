# Privacy Policy — Code Comment Navigator

Effective date: September 16, 2026. Applies to plugin version 1.1.0.

## Local processing

Code Comment Navigator reads the active editor document inside your IDE to build comment headings and navigate to source lines. The outline and its folding state are held locally in the running IDE. The plugin does not upload source code, SQL statements, HTTP requests, comments, or file paths to the developer or an external service.

## Collection and network access

The plugin has no account system, advertising, analytics, telemetry, payment processing, or license activation service. Its navigation features do not send network requests and do not execute SQL statements or HTTP requests. Using the IDE's own Run or HTTP Client actions is separate from this plugin.

## Other services

JetBrains IDEs and Marketplace may process information under their own policies, including plugin installation and updates. Opening website, GitHub, or support links leaves the plugin and is governed by those services' policies. This policy covers the plugin, not analytics or hosting on external websites.

## Support

If you choose to submit an issue or send an email, the information you provide is received through GitHub or the email service and used to handle your request. Avoid including passwords, tokens, or confidential code in public issues.
