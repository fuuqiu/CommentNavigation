# Marketplace 截图

真实 IntelliJ IDEA 2026.2 窗口截图，使用独立配置和 `examples/commerce` 演示文件。图片未合成或添加模拟 UI。

| 图片 | 展示内容 |
| --- | --- |
| `01-sql-analytics.png` | 363 行分析 SQL；业务域、报表和 CTE 阶段的层级目录；跳转到第 39 行 |
| `02-commerce-schema.png` | 76 张表、1,068 行结构；展开商品和订单，折叠其他业务域；订单表位于第 309 行 |
| `03-http-workflow.png` | 商品发现、购物车、结算、订单和售后的四级 HTTP 请求目录 |

分辨率均为 1355 × 768，满足上传页推荐的最低 1200 × 760。

示例结构来自 Apache-2.0 许可的 macrozheng/mall。来源、固定提交、修改说明与上游许可见 `examples/commerce/README.md`。
